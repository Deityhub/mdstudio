# Vendored KaTeX assets

Generated by `bun run vendor:katex` from the `katex` package (see `VERSION`). Do not edit by hand.

- `katex.min.css`: KaTeX's stylesheet (the `font-display: swap` variant).
- `fonts/*.woff2`: KaTeX's math fonts, loaded on demand when a document contains math.
- `LICENSE-katex.txt`: KaTeX, MIT, Copyright (c) 2013-2020 Khan Academy and other contributors.
- `LICENSE-katex-fonts.txt`: the KaTeX fonts repository (github.com/KaTeX/katex-fonts), MIT,
  Copyright (c) 2018 Khan Academy. That repository states the fonts were originally based on
  MathJax's font generation, so the licensing of the underlying glyph designs should be reviewed
  with the project license audit.
